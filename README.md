# Dice Roller App
A simple iOS app that simulates rolling dice. When you press a button, it randomly generates and displays the outcome of rolling one or more dice.

## Features
- Press the button to roll the dice.
- Randomly generates numbers for each die.
- Displays the result of the roll on the screen.

## Technologies Used
- Swift
- UIKit

## How to Run
1. Clone the repository.
2. Open the project in Xcode.
3. Run the app on a simulator or device.
